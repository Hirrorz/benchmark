8常驻 benchmark（无 TUI，简单进度条）

8 个 rank 进程常驻占满 8 卡；预热后每次 prompt 只跑计算（目标 ~1s，硬上限 3s）。 终端 A 跑 host cache + server，终端 B 用 bench_cli 发 prompt。所有命令由本页生成。

使用说明（怎么跑 / 参数 / 口径 / 常见错误）

1) 三步跑起来

  1. 终端 A：先 npu-smi info 确认 8 张卡空闲（有别的容器进程就先别起）→ 需要 tp8 时手动开 host cache → 执行 bench_server.py start （前台阻塞，Ctrl-C 整组停）。
  2. 终端 B：bench_cli.py warmup（W1/W2/W3，带进度条）→ bench_cli.py run --prompt ... --chat（prefill → decode）。
  3. 收尾：bench_cli.py status/stop；host cache 是独立 daemon，必须单独 moe_host_cache.py stop。

每次重启 bench_server 都要重新 warmup（AC/池/形状缓存都在进程内）。

2) 参数

modeauto = 一律 ep8（同布局，P→D/D→P=0，decode 全量重算，最稳）； ep8 同上；tp8-fidelity = 真实 P→D/D→P（必须 host cache）； tp8-dual 未实现。
serve-l-max常驻池容量：prompt + decode 的总 token 数不能超过它（默认 1024， 不中途重分配）。超长请求会被拒绝。
预热阶梯每个长度第一次出现要现场建 rope/slot/元数据缓存；阶梯覆盖到 ≤L 时 首触也承诺 ≤3s。默认 16,32,64,128,256,512,1024，单桶约 0.15–0.2 s。
decode / repeat--decode 是上限；命中 EOS 提前结束是正常的。 repeat 从第 2 次起取稳态中位。
--chat用聊天模板（推荐开）。raw prompt 也会自动补长到 ≥16 token。
host cache只有 tp8-fidelity 需要：269 GiB，冷页缓存约 3–9 min（热约 3 min）； 用完手动 stop。

3) 指标口径

  • prefill：8 rank 取 max，不含 tokenize；实测 ep8 稳态 ~0.16 s、首触 ~0.34 s。
  • decode：每 token 单独计时（ep8 全量重算 ~0.26 s/tok；tp8 TP ~0.30–0.34 s/tok）， 首 token 不计入。
  • P→D / D→P：ep8 都是 0；tp8 P→D 2.5–3.2 s、D→P 4.9–5.5 s， D→P 后下一 prompt prefill 1.8–2.2 s。
  • 承诺：L ≤ 预热阶梯最大值（且 prompt+decode ≤ l_max）时 prefill ≤3 s； 超出显示实测、不承诺。

4) 注意事项

  • 共享卡：起服务前 npu-smi info 要是 8 张卡都没有别的进程。 被别的容器占着会出现 halSqCqAllocate / RunAicpuCommInit 这类驱动错误：停服务、等 20–30 s、确认空闲再重启；不要 kill 别人的进程。
  • 根盘紧张：勾选“临时目录放共享盘”，并在终端 B 也 export 同一个 DS41_BENCH_ROOT。
  • prompt 补长：chat 在 BOS 后插空格；raw 在末尾补；full decode 用偶数长度 （单次 prefill，同时避开 mqsmla 的 T%4==1 trap）。
  • 文本显示：结果表格的“文本”列只放 40 字预览，完整文本在下面单独打印； 命中 EOS 可能只是正常句末。
  • 日志：<logdir>/rank*.log + all.log； 每次 run 结果里也会打印 tail -f 命令。

5) 常见错误

prompt + decode > 池容量加大 --serve-l-max 重启； 池不中途重分配。
tp8 需要 host cache先 moe_host_cache.py start，或改用 ep8。
halSqCqAllocate / aicore exception共享卡被占或驱动状态差：停服务、等 20–30 s、npu-smi 确认空闲后重启；反复出现找管理方清容器/驱动。
RunAicpuCommInit … get kernel failedHCCL 通信域 lazy init 失败； 新版启动会先预热 WORLD 域。仍失败按上一条处理。
文本停在半句先看完整文本/ids：命中 EOS 是正常结束；表格里只是 40 字预览。
控制连接断开 / rank 超时有 rank 异常退出，看门狗整组杀（HCCL 不能单 rank 重启）；重启服务并重新 warmup。
host cache 是独立 daemon，手动开/停；只有 tp8-fidelity 需要， 全量 268.9 GiB，冷页缓存约 3–9 min（热约 3 min）。
